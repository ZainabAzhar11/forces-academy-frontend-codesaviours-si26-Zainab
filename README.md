# 🛡️ Force Academy Website

Force Academy is a modern and responsive educational website designed to provide information about academy programs, courses,admissions, student results,students gallery selections, and contact details.

The website provides students with an easy-to-use platform to explore courses, check results through roll numbers, view latest selections, and get information about academy services. The design focuses on a professional look, responsive layout, and smooth user experience across desktop, tablet, and mobile devices.

The project focuses on a clean user interface, responsive design, smooth animations, and an interactive result checking system. It is designed to work smoothly on desktop, tablet, and mobile devices.
